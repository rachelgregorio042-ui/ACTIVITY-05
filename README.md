# GREY | Photography Landing Page

A photography landing page built with HTML and CSS, featuring a clean navigation bar, a creative hero section, and a three-image gallery.

## Features

- Navigation bar with Home, Pages, Photography, and Photoshoot links
- Hero section with a headline and introductory text
- Sign-in and login links
- Photography image gallery
- Responsive viewport configuration

## Technologies Used

- HTML5
- CSS3

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.

## Project Purpose

This project was created as a web development activity to practice HTML structure, CSS styling, navigation layout, and image presentation.
